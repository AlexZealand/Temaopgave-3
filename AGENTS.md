
# Tema 3 – Halloween Horror House

## Projekt
- Ny hjemmeside til Temaopgave 3 på multimediedesigneruddannelsen.
- Primær persona: Carla.
- Særligt fokus på tilgængelighed for personer med protanopi.

## Teknologi
- Brug semantisk HTML5, CSS3 og vanilla JavaScript.
- Undgå frameworks og unødvendige dependencies.
- Organisér kode og assets logisk og enkelt.
- Understøt mobil, tablet og desktop.

## Design
- Figma-wireframen er reference for den foreløbige struktur.
- Det endelige visuelle design er endnu ikke godkendt.
- Opfind ikke endelige farver, fonte, illustrationer eller layouts.
- Ændr ikke Figma-designet uden udtrykkelig tilladelse.
- Afklar væsentlige uoverensstemmelser før implementering.

## Tilgængelighed
- Tilstræb WCAG 2.2 AA.
- Brug ikke farver som eneste informationsbærer.
- Sørg for semantik, tastaturnavigation, synligt fokus og tilstrækkelig kontrast.
- Tag særligt hensyn til protanopi.

## Arbejdsregler
- Følg den konkrete opgaves afgrænsning.
- Foretag ikke uvedkommende ændringer.
- Ingen commit, push eller deployment uden udtrykkelig godkendelse.
- Beskriv ændrede filer og udførte tests.
- Påstå aldrig, at en test er bestået, hvis den ikke er udført.
- Bevar eksisterende funktionalitet ved senere ændringer.
- Svar på dansk.
